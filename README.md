# Chaxter releases

The public home of every Chaxter release: the signed desktop installers for macOS, Windows and Linux, the `latest.json` manifest the desktop app reads to update itself, and the release notes of each version.

Chaxter is one live session your coding agents share — open on every tab, every browser and every machine you own. Its source repository is private; this repository carries only the application deploys and their notes.

Each release is published under **Releases**, one per version tag.
