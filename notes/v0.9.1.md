## Chaxter v0.9.1

Two milestones since v0.8.3, one supervision fix, and three release-pipeline fixes. v0.9.0 was tagged on the same milestone work and never published: its release run failed twice (the notes exceeded the action's argument limit, then the macOS and Windows bundles broke on a file-name collision), so this is the first published release of that work. Squash merges do not read as conventional commits and the generated notes would list only the last fix; this is the full picture.

### The fleet surface — milestone 25 (#1389, spec #1104)

- **Session roster** with the quadrante and the honesty line: partitioned into headed bands with counts, urgency-first ordering, an attention counter that is one number with the blocking segment, and an honesty line that says what the roster cannot see.
- **Supervision dock** and its occupants: the queue board (in-flight card names what runs, since when, and the permission that blocks it; a reloaded author gets their entries back), the session timeline, the turn graph rooted at the session, and the turn trace.
- **Pane strip — two to four panes**: pane model, focus, URL arrangement (`/#a,b?focus=b`, pins), admission bound on restore, the cap that refuses and says why, meta-click and shift-click to open beside, presence per pane, one sign-in dialog whatever the pane count.
- **Instruments**: la striscia (blocking strip, ten-minute window), il nastro (the tape), the turn grid (six fixed slots, newest at the right edge, failure and unknown as their own tones), le corsie (swimlanes with a legend).
- **Cross-session channel**: Hub channels, the write lease, the prompt queue stopped by a permission.
- Certified by three adversarial rounds and 249 use cases (`docs/analysis/ml25-dev-ml-round1/`).

### ACP agent catalogue — milestone 28 (#1384, spec #1371)

Provisioning of ACP agents from a catalogue: enable, install (pinned versions, per-platform channels, receipts), the pre-session gate that installs on first use and says what it is doing, update notices on a live session with a lease-holder-only apply, the diagnostics panel, sign-in flows (device code, cancel recovery). Certified with a real install (`docs/analysis/acp-agent-catalog/`).

### Bringing the two together

Milestone 28 was merged into 25's tree with an adversarial verification of the merge itself: five of 28's single-handle stores were made per pane (`hubRecoveryStore`, `agentRunningStore`, the pending sign-in, `connectErrorTap`, `retryNoticeStore`), a session list from one agent process now upserts into the roster instead of replacing it, a deletion reaches every attachment, and an update notice reads only the applies its own edge ordered.

### Supervision (#1156)

The Hub can die and the app comes back: supervision, respawn, and a leak gate that can fail.

### Release pipeline and desktop build

- **Release notes reach the action through a file and stay under the limit** (#1403): the expanded notes of a squash-merged milestone no longer overflow the process argument list; a cap keeps the body under GitHub's size limit and names the pull requests it left out.
- **One CI runner per E2E shard** (#1405, #1404): the Playwright suite runs as 18 shards, a pull request's end-to-end gate went from 80 minutes to 13.
- **The blocking-strip model no longer shadows its component on case-insensitive disks** (#1406): `blockingStrip.ts` beside `BlockingStrip.tsx` built on Linux and failed the macOS and Windows bundles; the model is renamed and a gate refuses two module names in one directory that differ only by case.

### Known follow-ups

One sign-in elicitation per pane (today one slot for all panes); the fleet rank of a session whose last turn ended unreported; the composer bar's fold thresholds re-measured with the permission chip; the Vite build on macOS and Windows in pull requests (#1415).
