### Highlights

- Share a live browser page with a session and let the agent read and drive it, with the share revoked when you navigate away.
- Export a whole transcript as Markdown or a self-contained HTML file, with a secret scan and a warning before anything is written.
- A ports panel lists the local servers running beside your session and opens a preview for the HTTP ones.
- Send a message into the turn that is already running instead of queueing it behind.
- Branch a session into a fork, or open a quick side question, without disturbing the conversation you are in.

### Features

- Share a live browser page with one session; the agent can read it, click and type in it, and the share ends when the origin changes.
- A browser panel every tab watches, with the shared page's state mirrored on the session rather than on the tab that shared it.
- A ports panel listing the local listeners, with a proxied preview for HTTP ports.
- Export a transcript as Markdown or a self-contained HTML file, after a pre-flight secret scan and a warning before the file is written.
- Fork a session into its own branch, nested under the session it came from, with its own history.
- Ask a quick side question in a popup on an unlisted branch that is deleted when you close it.
- Close a session from the roster, page through long session lists, and see which rows were started from the command line.
- Send a runnable command from a transcript fence straight into the terminal drawer.
- Follow the agent in the editor, as an opt-in setting.
- The terminal login now draws a real screen in every tab, and its sign-in address is a whole, copyable link.
- Apply a saved agent environment right away and restart the agent onto it.
- Agent questions and forms are cards in the transcript instead of modals, are replayed after a reload, and secret answers go to the secrets store rather than the record.
- Permission options say what they grant and for how long, show a countdown, and can be armed as a one-shot approval.
- A session-wide permission mode that every tab sees, so one session has one answer.
- Settings lists every remembered permission and lets you revoke one; each remembered grant carries its agent and its expiry.
- One notification per permission request, tagged, deduped and closed when the request is answered.
- A dock panel that tracks background subagents live, and subagent tool calls rendered under the call that spawned them.
- Per-turn token usage and cost, read from the agent's own record.
- Edit a queued prompt in place, keeping its position and attribution; a held queue entry says why it is not running.
- Session creation, renaming, closing and turn endings reach every open tab, not only the one that acted.
- A diagnostics screen that answers whether an agent will actually start, and tells 'not installed' from 'will not start'.
- A per-agent login check that says when an agent is signed out.
- The desktop update is armed and installs once every session is idle.
- Deleting a session asks for confirmation only when a turn would be lost.
- Commands that ask for elevated privileges are refused before they reach a terminal or a permission prompt.
- Attaching read-only to a cold session serves its history without starting the agent.
- The tool card renders the agent's own context compaction.
- When the server is at capacity, the wait states why and how it ended.

### Bug Fixes

- The composer sheds and restores its action labels gracefully on a narrow row, and keeps the permission chip readable.
- Text typed or pasted into the welcome composer is kept, carried into the session it starts, and dropped when you cancel the dialog.
- New session opens on the workspace you are looking at, and a session held by two workspaces is listed once.
- Renames and deletions made in one tab now converge in the others, including tabs that are not attached.
- A held or refused history load explains itself in the pane instead of leaving it blank or claiming an empty transcript.
- Each pane keeps its own transcript, permission dialogs and reconnect state, so two panes no longer write over each other.
- Permission cards show the whole target path and every declared path, wrap long arguments and options, preselect nothing, and no longer paint over their own countdown.
- Remembered-permission wording states the real expiry and names who set a standing rule; 'Always allow' is offered only when the grant is actually kept.
- A refused command is shown as not run on its tool card and in the terminal, and offers a way to run it rather than only to copy it.
- A send that never reached the agent leaves nothing in the transcript, hands your prose back and stops calling a sent message unsent.
- A forked session takes its own title from its own first prompt, and long branch badges truncate instead of pushing the title out.
- The turn trace shows how a turn ended, who stopped it, and the stop reason is cleared when the next turn starts; reattaching tells you how the last turn ended.
- Sign-in addresses are surfaced whatever the login flow, taken whole, and redacted before they reach the protocol log.
- A restart you asked for is no longer painted as a fault, and the login row states a restart failure as one.
- The ports panel names processes in full, stops offering previews for non-HTTP ports, says when it is still looking, and forgets its snapshot when the connection dies.
- The export summary reports the list it stands over, gives sizes in bytes, and keeps its secret warning for real credentials.
- A half-typed answer to an agent's question survives a link drop and is cleared when the question is withdrawn; a read-only tab can leave a question it cannot answer.
- The connection chip says Reconnecting while it is redialing and otherwise agrees with what the app is doing.
- The workspace browser says whose file list it is, explains an untracked file instead of showing 'No changes to show', and re-reads status when an editing turn ends.
- Secrets in the agent's environment are masked in its output, credential-helper variables are withheld from agent-spawned processes, and the session store is created owner-only on disk.
- The turn readout shows all five token counts and names the cache half it reads; a turn that auto-compacts is billed for it.
- Under a read-only lease the send is refused out loud, including image pastes, while the keyboard and palette still reach your draft.
- Only one update install runs at a time, an armed install gets a retry control, and the hold survives a manual check for updates.
- Deleting a session with unsent prose or an unseen transcript asks again, and a second unconfirmed delete is refused.
- The shared browser page receives the keyboard and the wheel without also firing app shortcuts, and focus shortcuts no longer chase a target a dialog has hidden.
- On Windows, a path ending in a backslash stays sendable, packaged agents resolve to their real command, and agents start without a console window.
- Italian wording corrected across the agent name, the sign-in disclosure and the permission labels.
- Session rows identify themselves when unnamed, the hover rail no longer hides the title, and the dock strip folds so ten tabs stay in view.
- A steered message is echoed to every tab, billed to the turn it joined, and is offered only where a turn is actually running.
- Queue controls stop promising an outcome the server decides, and a prompt abandoned before it ran settles instead of hanging.

### Performance

- Long agent terminal output renders without re-reading the whole buffer.
