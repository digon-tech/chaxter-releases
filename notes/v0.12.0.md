### Highlights

- The sidebar is now a session organizer, with workspace groups, Archived and Trash sections, sorting and grouping, inline rename and per-session notes.
- A failed prompt now appears as a transcript row that explains the provider's refusal and offers Retry, in every open tab and after a reload.
- Search the current conversation with mod+F.
- Bookmark any agent message and reopen it from a searchable Saved list in the dock.
- Type / in the composer to run Chaxter's own commands without sending them to the agent.

### Features

- A session organizer in the sidebar: workspace groups, Archived and Trash sections, folding headings and a draggable divider.
- Sort, group and show-archived controls for the session list, remembered per browser.
- Archive, restore, trash, delete forever and empty trash, each confirming and stating plainly when an action is refused.
- Rename a session or add a note in its own row, and rename a workspace from its heading.
- Session rows show age, agent, section glyph and notes, with a badge order you can set in Settings.
- Archived and trashed sessions open read-only, with a strip saying why.
- A slash popup in the composer for Chaxter's commands, with Tab to insert and its own preferences in Settings › Chat.
- Search the transcript with mod+F.
- Bookmark an agent message and open your saved messages from the dock; the Saved list is reachable from search.
- Retry a refused prompt from the transcript, whatever kind of failure it was.
- A refused turn is raised as a transcript row and shown on every attached tab.
- Each message records the model and effort it was sent with, and a boundary row marks a model switch.
- Messages carry the time the server received them, and a reload restores the model credited to each reply.
- Jump to the start of a message, skip to the next one, and jump to either end of any capped scroll box.
- A skip link takes the keyboard straight to the conversation.
- The composer says the agent is starting, from your first message.
- The new-session dialog opens on the workspace you started it from.

### Bug Fixes

- A deleted session stays deleted across a reload and leaves the list on the client that deleted it.
- Activity is filed under the session it belongs to, and a second conversation gets its own record.
- A turn's ending — a stop, a crash, a killed process or a missed deadline — now reaches every attached tab.
- Two tabs reloading the same session are replayed one at a time, and a load waiting behind another tab's replay says so instead of claiming a turn is running.
- A reconnecting tab still receives the transcript, and a reconnected author is told why their turn failed.
- Failure rows state what happened once, keep their reason after a reload, and place Copy beside Details.
- A provider's remediation address is a link, wraps only at its own delimiters, and can be copied in one press.
- Retry re-sends the same prompt, reuses its row, and numbered attempts stay grouped under the message.
- Refusals stay under the turn they belong to, survive a model switch and an agent restart, and no longer follow you into another conversation.
- Failure kinds are classified correctly: a refused API key, a spent quota, an unsupported model or a dead agent process is no longer reported as a temporary error.
- The model menu marks a value the agent no longer offers, carries the agent's own descriptions, accepts a custom model id and can be filtered.
- A sticky model is re-applied only to the agent it was picked on.
- A model switch retires the previous model's usage readings while keeping the session's running cost.
- Usage and context figures are grouped for your language, separated from each other, and flagged when over the limit.
- Code blocks return highlighted after a remount and keep their collapse state and horizontal position.
- A find lands on the occurrence, opens a collapsed code block to show it, and clears only the highlight it painted.
- Terminal panels keep your place across a remount, follow the tail only while you are at the bottom, and say when they are pending or waiting for output.
- The permission dialog pins its header and answers, scrolls its body, and stacks three or more options at one width.
- The composer stops waiting for an approval the moment it is given, and a queued prompt stays in the queue strip until it is dispatched.
- Typing the first character no longer shifts the transcript, and sending brings you back to the tail.
- The session list follows the active row, keeps one row per session after a re-attach, and orders the same way in every tab.
- The session list's loading state reads as loading rather than as a failure, and no longer names a session count.
- Clicking a pinned session re-dials the agent that session belongs to.
- The top bar names the agent once, and the same way before and after its handshake.
- Notices about a lost connection, sign-in or unavailable tools retire when the pane changes conversation, and stop promising a reconnect that is not coming.
- Narrow layouts fold the top bar, give agent-row actions their own line, and stop cutting off the model chip.
- Keyboard focus follows the cursor rather than a press, hover controls keep their names and stay clickable, and failure rows are announced.
- Message times keep their slot, swap to the absolute form on a press so touch can reach them, and drop the year when it is not needed.
- Saved messages preview as plain text cut on a word, show when they were saved, and only agent messages can be bookmarked.
- An attached text file shows as its filename in the sent bubble.
- Italian keeps its accents and gets corrected wording for agents, tool cards, quotas, buttons and saved times.
- The server shuts down on SIGTERM with connections still attached, and exits with an error when it cannot bind.
- Opening an existing session roots its workspace on that session's directory.
- The Modified files panel reads neutrally when no workspace is connected yet.
- Refused purges and empty-trash attempts read as a sentence rather than a raw translation key.

### Performance

- Message time formatting is prepared once per language instead of on every render.
