### Highlights

- The desktop app now checks for new versions on its own and offers a one-click update from the About card.
- The running version is always visible, with an Update pill when a newer build is out.
- A new What's new section in Settings shows the notes for each release, including a bundled copy when you are offline.
- You can re-check for an update on demand instead of waiting for the next automatic check.
- A browser tab left open on an updated server now offers to reload itself.

### Features

- Automatic update checks on the desktop app, with the current version, an Update pill and an update card in About.
- A What's new section in Settings that shows the release notes for each version.
- Manual re-check for updates, plus bundled notes so What's new still works offline.
- Updates are offered only in released builds, and Windows installs are delivered as an installer package.
- The Linux install form is now detected from the actual package you installed, so the update instructions match it.
- A tab left open against a server that has since updated is told to reload.
- The Settings dialog has been rebuilt to the approved design.

### Bug Fixes

- An update that is already downloaded is no longer thrown away, and an out-of-date version comparison can no longer swallow a click on the update button.
- What's new says "no release notes yet" instead of spinning forever, loads notes reliably, and its badges now match the build you are running.
- Update prompts no longer appear in the browser, where they cannot do anything.
- The one-sentence release summary is now a real sentence.
- Better contrast on the active side-rail item in dark mode, and the version rail lines up with the rest of the panel.
