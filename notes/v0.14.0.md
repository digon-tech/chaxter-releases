### Highlights

- Add MCP servers, skills and plugins once in the new Library and every agent can use them, with each agent's own servers, skills and plugins listed beside them and switchable.
- Choose the tools each chat gets from the tools chip and «In this chat», see what each connection costs per message, and save a set of tools to reuse.
- Subagents are first-class: they nest under their conversation, open in their own read-only pane with Stop, and say which one is asking.
- Commit, switch or create branches, push and browse History straight from the modified-files panel.
- The interface stays fluid with many sessions open: hidden tabs stop polling and animating, and the sidebar redraws only the rows that changed.

### Features

- Settings › Library lists your MCP server connections; Chaxter runs each one and hands it to every agent.
- Add a connection from the catalogue, a pasted configuration or command line, a goose, VS Code or Cursor install link, or an .mcpb bundle; Linear, Notion, Stripe, Atlassian and Figma join the curated list.
- Sign a remote MCP server in from the Library and out from its sheet, with its token kept and refreshed for you.
- Secrets you paste, even inside an argument or a URL, are hidden and stored safely; see what was hidden, put it back or hide another part.
- A program that does not run through npx, uvx or Docker gets a clear warning on the consent sheet before it can start.
- «Always allow» a tool of a server you added, remembered per server and tool and forgotten when the server changes.
- A new connection is checked once when added, and its card shows its log and a switch to turn it on or off.
- See a connection's pinned and latest version, update it or roll it back, or turn on auto-update per source.
- Add directories to search: the Docker MCP Catalog, the Gemini CLI extensions gallery, goose, Kilo, Smithery, SkillsMP and your own git marketplaces pinned to a commit.
- A tools chip and an «In this chat» panel show a chat's connections, let you tick single tools and show what each costs per message.
- Save a chat's ticked tools as a set and switch a chat to another set in one step.
- A changed connection list is applied to running chats, saying how each agent takes the change.
- The Library lists each agent's own MCP servers, skills and plugins with a switch or where to turn them off, and can adopt a server into your list.
- Write your connections into Stakpak's own settings, opt-in, and see how Chaxter reaches agents that take no server list.
- A Skills tab installs a skill after showing it whole, switches it on and off, and shows when an agent last used it.
- Keep a skill to one project or one chat, or switch it off in a single chat; installed skills appear in the / list.
- Each skill shows its latest commit and any drift from its pin, with update, rollback and auto-update.
- A Packs tab installs and uninstalls plugins and shows each pack part by part, hooks included.
- A pack is enabled whole on Claude Code, CodeBuddy Code, Qwen Code, MiniMax Code and Grok Build after a preview; other agents get its connections and skills.
- On Claude Code a pack can be kept to one chat and switched per chat.
- Gemini CLI extensions install as packs, naming their context files and the tools they keep.
- The «One agent» tab and each agent's details show its connections, skills and their health.
- In the desktop app, chaxter:// links open an install on its confirm sheet, and Share passes a connection on without its keys.
- Team members get the lead's connections and Chaxter's tools, ticked by default, and keep them when revived.
- When an agent is refused sudo, or a server command starts with sudo, Chaxter offers to run it in a terminal you control.
- Test a Kimchi connection from its row, and see Harn's own servers and their sign-in in a Harn chat.
- Subagents nest under their conversation in the sidebar, counted with a robot icon and folded past six.
- A subagent opens in its own read-only pane with its state, Stop and a way back, from the dock or from the tool card that started it.
- A permission or question from a subagent says which subagent is asking.
- Subagents are shown for Claude Code, including past conversations, and for Codex, Devin, goose, MiniMax Code and other agents that report them.
- A failed prompt shows the agent's own reason with Sign in, New session and Retry on every window that can write.
- Restart now sits beside the failure setting and, after asking, can stop a running turn.
- Branch a conversation from any answer, and see which files the last turn changed.
- A session goal shows above the composer with the actions the agent offers, and plans in markdown or files show beside the checklist.
- A composer bar settings page orders the row's controls and turns any off, keeping them in the overflow menu.
- The composer shows context usage as a small bar with a percentage, and cost as its own badge.
- Compaction rows show their figures and kept summary, each turn shows its tokens by model, and Claude's rate-limit window appears before you hit it.
- Agent notices show as a banner on every window, and goose, Grok and Mistral Vibe show their retries and progress in plain words.
- Questions gain an Other box each, option previews, the agent's reason, a Codex plan review's plan and an auto-answer countdown.
- Add instructions in an agent's settings, sent on every session it opens.
- A delegated sign-in shows on every window with how long it works, Mistral Vibe signs in from a browser on another machine, and agents sign out from their card.
- Modes that grant full access are flagged, and the agent's recommended model and effort carry a small tag.
- Git from the files panel: commit with a Not committed view, switch or create branches, push, browse History 50 commits at a time and use «Suggest a message».
- The update pill shows what's new before installing, and Chaxter asks before an update or launch stops a command you started.
- «Enable preview» lists pre-release agent versions, and the agent pane says what its installed version cannot do.

### Bug Fixes

- Commits record ticked deletions, renames, symlinks and hook-staged files as git has them, respect git's lock, and refuse a nested repository instead of committing it empty.
- A hook is blamed only when git says one refused, and a branch switch whose after-switch hook failed is reported as made.
- The commit, push and branch dialogs stay anchored, keep their buttons still, survive a reconnect, a resize or a zoom, and give focus back after a refusal.
- A commit's outcome shows only in the session that made it and wraps instead of cutting «Pushed to …».
- History keeps the open row in view and your place when «Load 50 more» lands, and a repository with no commits shows an empty page.
- Git failures show git's own words behind Details, and file names that look quoted show as written.
- The files a turn changed and the session goal survive a restart and reach a tab opened afterwards.
- A subagent's question or permission is asked on the main conversation, counted once, and cancelled when the subagent ends.
- A subagent you stopped reads stopped, not failed, and Stop ends a conversation's running subagents on every window.
- Delete confirmations name the subagents that go with a conversation, and the palette no longer offers a subagent to resume.
- A failed prompt keeps Retry, «Put back in composer» and Sign in after a reload or a dropped connection, and signing in re-sends it once.
- A turn the agent leaves unanswered reads as failed on every tab instead of looking finished.
- An agent's question reads as a question, not a permission, in the sidebar, notifications and the composer.
- Codex MCP calls show their tool, server and progress on the card, and Codex read output stops showing Running once closed.
- Gemini's API-key login offers a key field, and words added mid-turn reach the running turn on agents that accept them.
- A moved Claude conversation and its subagents land under the project folder it is filed under.
- A conversation history cut short by a crash is repaired before anything new is written to it.
- A permission request that claims to read but writes is refused, and a standing approval never answers an agent's question.
- Stop is drawn as an icon at Send's size, so the controls row never moves.
- The composer row folds from the end of your order as the window narrows, and the plan chip shows in a pane with no composer.
- The agent chip stays first in a tight top bar and Tab can no longer scroll it away.
- The terminal strip opens its shell at its drawn size, without a scrollbar.
- What's new keeps its notes when only the check time moves, and a window with no chat learns of a new release.
- Streaming replies reveal at a steady pace on any display, and code blocks are highlighted without stalling the reply.
- Background tabs stop their timers, polls and hidden animations, and a busy window is no longer dropped as unresponsive.
- The sidebar, command palette and session list redraw only what changed, keeping large workspaces fluid.
- Secret detection fails safe: more key names, credentials in headers and URLs, and values hidden behind references.
- A pasted command that hides part of its program, or steers its installer through the environment, is refused with a reason.
- Docker settings and other plain settings are asked in clear, and only real secrets are stored as secrets.
- A shared link's settings are asked in clear on the second machine and never carry a secret.
- Grok Build runs at its pinned version, or says why it refuses, instead of reporting a failed download.
- DeepAgents starts on an OpenAI model when OpenAI is its only key.
- A Claude Code setup that locks down MCP servers now starts its chat without them and says so.
- An agent missing an API key or part of its install says so plainly, not as a model error.
- Windows reads the system PATH when Chaxter starts, and a missing Node.js is named only when it is missing.
- A server whose key was rotated restarts with the new one, and a remote that loses its session starts a new one.
- An uninstall that stops part way names the agents the pack could not be removed from.
- Narrowing a skill removes its project copies, and a skill switched off in a chat leaves its / list.
- Forked chats and revived team members keep their own chat's tool switches.
- MCP results that are JSON keep their indentation, and tall dialogs stay within the window.
- Connection search says «Nothing found.» only once every directory has answered.
- A sudo command offers «Don't run it» until it starts and «Stop» after, naming the connection it is for.
