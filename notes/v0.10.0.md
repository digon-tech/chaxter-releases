### Highlights

- The desktop app can update itself: the running version is always visible, an Update pill appears when a new build is out, and the update card lives in About.
- A new What's new section in Settings shows the release notes for each version, with bundled notes available offline and a manual re-check.
- Settings is now one scrolling column with a rail of anchors and a sticky section heading, so you can see where you are.
- The Windows desktop build now starts on a clean machine.
- Selecting an agent keeps the list in place — details open in a pane pinned beside it.

### Features

- Desktop self-update: the running version is always visible, an Update pill appears when a newer build exists, and the update card sits in About.
- A What's new section in Settings shows release notes per version, backed by notes bundled with the app when you are offline and a manual re-check when you want fresh data.
- Settings is one scrolling column with a rail of anchors and a sticky section heading, and the whole dialog has been raised to the new design.
- Keyboard settings show one chip per key, with row actions revealed on hover.
- A stale browser tab is told to reload once the machine it is connected to has updated.
- On Linux, the install instructions match the package you actually installed.

### Bug Fixes

- The Windows desktop app starts on a clean machine, and a workspace setup that cannot find git now tells you where it looked.
- "Check for updates" is refused while an install is already running, re-polls so an earlier failed check can clear, and never throws away an install that is ready to apply.
- What's new says "no release notes yet" instead of spinning forever, and its badges match the build you are actually running.
- About is a Settings section rather than a footer, and it makes no claim about being up to date until something has confirmed it.
- Opening a settings section scrolls the column smoothly to the right place instead of jumping, and the version list no longer scrolls on its own.
- Selecting an agent no longer sends the list scrolling: details open in a pane pinned beside it, reachable by keyboard and properly labelled.
- The pinned band sits flush, labels are no longer clipped mid-word, and a detail header's name cannot be squeezed down to a single letter.
- The active rail marker now meets AA contrast in dark mode.
- External links open again instead of being refused.
- Searching Settings hides non-matching sections instead of tearing them down.
- One unreadable entry in the release history no longer blanks the whole list, and a release that was never published can no longer be shown as the latest one.
- The health endpoint answers only allow-listed origins, and release data fetched from the network is bounded in size.
