### Highlights

- Deleting a session now removes its record and transcript for good, and the row never reappears in the list.
- A session takes its name from the agent's first title and keeps that name across reloads.
- Code fences and diagrams render while the agent is still writing them, instead of appearing only when finished.
- When the connection comes back, the session list reloads, the lost-connection banner clears, and stale refusals are withdrawn.
- Dialogs, overlays and the command palette give the keyboard back to whatever opened them.
