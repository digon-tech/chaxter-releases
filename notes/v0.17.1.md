### Highlights

- The desktop app now notices when its background service stops and starts it again on its own.
- Folders without git open in the workspace, and the file browser lists and pages through them instead of refusing.
- Long session lists open faster and come back scrolled to where you left them.
- Closing a dialog or menu now returns the focus to the row you opened it from.
- The agent screens lead with version and path, and say plainly what each installation is.

### Features

- The desktop app watches its background service and starts it again if it goes away.

### Bug Fixes

- The background service is restarted on a widening retry schedule, and the restart notice clears once it is back up.
- An authenticated request keeps the desktop background service awake.
- "Version" now reports the release of the installed desktop app.
- Folders without git open in the workspace, with only the git-dependent parts of the panel unavailable; closing a commit returns you to the workspace either way.
- The file browser lists and pages through folders without git, and says where a long listing stops.
- "Load more" stays available while a folder without git is being read, and a resumed listing no longer breaks off.
- The file tree can take up to 40% of a tall browser instead of a fixed short height.
- The History dialog grows with its list, up to its maximum height.
- Session lists draw a screenful on first open instead of every row, so long lists appear faster.
- The session list returns to the scroll position you left it at.
- Collapsing the left panel keeps the session list loaded, so it stays current when you reopen it.
- An Archive action appears on the hovered session row, and after archiving with the keyboard the focus moves on to the next row.
- The row menu offers export only for rows that can be exported.
- Session and folder titles stay readable in a narrow sidebar, on hover and with the keyboard.
- Folders with no rows to show are no longer drawn, and a folder that reappears is placed above the archive.
- Hiding the session list closes its hover card and releases the held ordering.
- Hover cards explain staleness and usage in plain sentences, and no longer open on top of a row icon.
- Closing the export dialog with the mouse or Escape returns the focus to the row it came from, and the card stays closed.
- A picker that steps aside for another dialog no longer loses track of where the focus should go, and only one modal is open at a time.
- Settings controls keep their width beside their labels, long text wraps instead of squeezing the label, and the keep-alive column shrinks again in a narrow window.
- The settings navigation keeps the selected section in view.
- Opening Agents gives both the list and the detail their space, and keyboard landings keep the relevant row and pane in view without an unexpected scroll.
- The agent pane's wording is plainer and no longer repeats itself, and spacing under the tallest section is consistent.
- The installed-versions badge says what it is counting, short agent names leave room for the version, and the installation picker leads with the version and the path.
- The legacy OpenCode entry explains when to choose it.
- A user installation's version is read from the package it links to.
- Enabling an agent takes you to the Install action, in view and focused, with a note on what is missing, and a completed Install shows the focus ring.
- A branch with no name takes the name its agent reports.
